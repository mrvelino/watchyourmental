# watchyourmental
Sistem Pakar Mental: Pemetaan Awal Gangguan Kepribadian

Aplikasi berbasis web ini merupakan sistem pakar berbasis aturan (rule-based) untuk pemetaan awal 10 gangguan kepribadian. Sistem menggunakan 50 aturan IF-THEN yang disusun dari indikator perilaku dalam buku Essentials of Abnormal Psychology (Bridley & Daffin, 2019), dengan metode forward chaining untuk penalaran dan certainty factor untuk mengukur tingkat keyakinan setiap hasil.

Pengguna dapat menjawab kuesioner gejala (Ya/Tidak) atau mengunggah dataset Anxiety and Depression Mental Health Factors untuk eksplorasi batch. Setiap hasil ditampilkan bersama aturan yang aktif sehingga alasan di balik kesimpulan dapat ditelusuri.

Aplikasi ini adalah alat edukasi dan pemetaan awal, bukan alat diagnosis. Sistem tidak dilatih maupun divalidasi secara klinis, sehingga hasilnya tidak dapat menggantikan asesmen oleh psikolog atau psikiater.

Dibuat oleh Kelompok 3 untuk mata kuliah Sistem Pakar, 2025.
